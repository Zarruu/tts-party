# TTS Party

TTS Party adalah game Roblox teka-teki silang dengan gameplay word connect:
pemain menyeret huruf untuk mengisi kata pada papan TTS. Proyek ini memakai
Luau strict, Rojo, dan Roblox Studio.

## Memulai

Dokumen desain dan rencana kerja ada di `docs/`. Struktur kode mengikuti
pemetaan Rojo yang dijelaskan di `docs/SPEC.md`. Toolchain dan perintah
pemeriksaan akan ditambahkan pada tugas M0 berikutnya.
